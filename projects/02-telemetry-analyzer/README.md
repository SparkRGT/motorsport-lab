# F1 Telemetry Analyzer

A Python-based motorsport telemetry analysis platform for processing, validating, visualizing, and comparing telemetry data generated by EA SPORTS F1 25.

## Project Objective

The goal of this project is to transform recorded telemetry generated by EA SPORTS F1 25 into structured engineering-oriented analysis.

The analyzer will progressively support:

* telemetry dataset validation
* lap segmentation
* lap performance metrics
* sector analysis
* speed traces
* throttle and brake analysis
* lap-to-lap comparison
* distance-based time delta analysis
* driving event detection
* engineering-oriented visualizations

## Data Source

The primary data source is UDP telemetry generated by EA SPORTS F1 25.

This project does **not** use real Formula 1 vehicle telemetry.

The analyzed data represents the behavior of the vehicle within the EA SPORTS F1 25 simulation environment.

## Project Architecture

The project is designed as an analysis layer over recorded telemetry data produced by the Motorsport Lab telemetry collection workflow.

```text
EA SPORTS F1 25
       │
       ▼
F1 Telemetry Collector
       │
       ▼
Recorded Telemetry Dataset
       │
       ▼
F1 Telemetry Analyzer
       │
       ├── Validation
       ├── Normalization
       ├── Lap Segmentation
       ├── Metrics
       ├── Lap Comparison
       └── Visualization
```

## Current Status

Phase 0 — Project Foundation

The project is currently being prepared for telemetry dataset ingestion and analysis.

## Limitations

The telemetry analyzed by this project is generated by EA SPORTS F1 25.

It should not be interpreted as telemetry from a real Formula 1 vehicle.

Any engineering conclusions produced by the analyzer must be understood within the context and physics model of the simulation environment.
